Khái niệm cơ bản

Vercel là gì?

  • Nền tảng deploy & hosting cho ứng dụng frontend — Next.js, React, Vue, hoặc static site
  • Tự động build & deploy mỗi khi có commit hoặc pull request mới trên Git
  • CDN toàn cầu — tải nhanh ở mọi khu vực, không cần tự cấu hình
  • Free tier (Hobby) đủ dùng cho project demo, nội bộ và cá nhân

Tạo repository trên GitHub

  • Đăng nhập github.com → bấm dấu "+" trên thanh menu → New repository
  • Đặt tên repo, ví dụ vercel-deploy-slides, chọn Public hoặc Private
  • Bấm "Create repository" — vậy là có một nơi trống để chứa code
